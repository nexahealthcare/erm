# NexaERM — Frontend (GitHub Pages)

Antarmuka NexaERM (Nexa Health Care) sebagai situs statis. Semua data & logika ada di backend
Google Apps Script (REST API). Berkas yang boleh Anda edit hanya **`js/config.js`**.

```
index.html        halaman tunggal (SPA)
css/style.css     gaya
js/config.js      ← isi GAS_URL di sini
js/app.js         logika aplikasi
img/favicon.png   ikon tab
```

- Staf: buka `https://USERNAME.github.io/NAMA-REPO/`
- Pasien (konsultasi): `https://USERNAME.github.io/NAMA-REPO/?k=KODE`

Panduan lengkap: `PANDUAN-INSTALASI.md`.
